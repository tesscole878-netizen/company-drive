# Windows 苏盐新云盘连接助手

面向员工的图形界面客户端。安装后填写云盘地址、账号、网页登录密码，点击“登录并连接”，自动申请当前设备的连接密码、配置 WebDAV，并挂载为“苏盐新云盘（Z:）”。不需要员工操作 rclone 命令行，也不需要 Python。

助手 0.2.10 在连接期间用自己的窗口提醒文件更新，关闭 Windows 系统通知也能看到。助手收起到托盘后，提醒仍显示在鼠标所在屏幕的右下角。弹窗列出修改人、文件名和所在位置，同一时间的多条更新可滚动查看。点击右上角 × 即可关闭，鼠标移开后提醒会自动收起。自己和同事保存的文件均按当前访问权限提示。

助手在每次重新连接后复查已失效的苏盐云盘盘符，自动断开和手动断开留下的旧图标均会清理。

## 员工安装

1. 双击 `CompanyDriveSetup.exe`，在「安装位置」输入路径或点击「浏览…」，然后点击「安装连接助手」。已有安装位置会自动填入。
2. 从桌面“苏盐新云盘”打开助手。
3. 首次使用点击“安装磁盘组件”，允许 Windows 请求管理员安装 WinFsp。公司 IT 也可以提前统一安装该组件。
4. 填写苏盐新云盘首页地址、自己的账号和网页登录密码。服务器地址不需要包含 `/dav/`。
5. 点击“登录并连接”，资源管理器中出现“苏盐新云盘（Z:）”。如果 Z: 被占用，可以选择其他盘符。
6. 窗口关闭后，已连接的云盘留在托盘中运行；从右下角图标打开助手或断开/退出。

安装包已预填 `https://192.168.80.252:8443` 并内置公司公开证书。连接助手在应用内验证证书链、服务器名称和有效期，挂载组件使用同一公司证书，员工安装后填写账号密码即可连接。原 Windows 证书库由系统和公司 IT 管理。

电脑盘根目录中的「原 Seafile」显示本人原账号有权访问的资料。已有编辑权限的文件可直接打开、修改并保存回原 Seafile，历史版本由原系统管理。保存后等待助手上传完成再断开，版本冲突时先保留本地副本，再重新打开最新文件。新建、删除和普通改名在原 Seafile 操作，加密资料库通过原系统打开。此能力由服务器统一提供，已安装的同一版本助手可继续使用。

从 0.2.14 起，助手收到文件更新时会让电脑盘重新读取变更所在目录。若有文件等待写回，会等上传完成后刷新。

连接后可在主界面或托盘菜单打开「加密资料库」。输入原 Seafile 库密码后，可以只读浏览和下载。打开文件时先选择本地副本的保存位置。解锁仅限当前设备，关闭窗口会锁定，单次解锁最长 30 分钟。

从 0.2.12 起，“记住账号”只回填账号。本人勾选“记住密码”并成功登录后，助手会为当前 Windows 用户加密保存该设备的授权，下次连接同一服务器、同一账号时可以留空密码。取消勾选会立即清除本机保存的授权。仅勾选“开机打开助手”会打开登录窗口，同时勾选“开机时自动连接”才会在开机时挂载。旧版的账号记忆设置不会自动启用“记住密码”。

断开前请先关闭正在编辑的文档，等待上传完成。助手会检查上传队列，存在排队、进行中或失败的上传时，不直接退出。各盘符使用不同的网络映射地址，卷名显示为“苏盐新云盘”。0.2.6 版清理失效映射后，会同步通知已打开的「此电脑」窗口移除对应盘符。缓存按不同服务器和账号隔离，建议放在空间充足的磁盘。

## 管理员预填地址

在安装目录中的 `company.json` 设置：

```json
{"server_url":"https://你的苏盐新云盘域名"}
```

尚未配置个人连接时，助手会使用这个地址。制作公司分发包时，可以先填好此文件再执行构建；不要给员工预置管理员账号、密码或设备连接密码。

分发给其他电脑时，地址必须是 NAS/服务器可达的局域网 IP 或 HTTPS 域名。`127.0.0.1` 仅指员工自己的电脑，不能作为全公司的服务器地址。内网试点支持局域网 IP 的 HTTP；公司外地址使用 HTTPS。其他服务器使用系统证书信任与相同的名称、有效期校验。

## 安装和存储

- Windows 10/11 64 位；使用系统 .NET Framework 和打包的 rclone。
- 助手安装到当前用户的 `%LOCALAPPDATA%/CompanyDrive/app`，创建桌面和开始菜单快捷方式，不要求用管理员身份运行助手。
- WinFsp 是独立系统驱动，安装需要管理员确认。助手从官方版本地址下载，并校验 Windows 签名及发行者 NAVIMATICS LLC；它不绕过 UAC 或浏览器安全提示。
- 个人设置保存在 `%LOCALAPPDATA%/CompanyDriveClient/profile.bin`，使用 Windows 当前用户 DPAPI 加密。设备密码仅通过进程环境交给 rclone，不写入命令参数或明文配置文件。
- 如需撤销某台电脑，在网页“连接电脑”中撤销对应设备。账号停用或分组移除也会阻止后续服务端访问，已下载的副本仍保留。
- 此初版未做 Windows 代码签名。公司正式分发可使用公司签名证书或现有软件分发平台；系统策略是否允许运行需由公司 IT 确认。

## 构建

在 Windows 上运行 `build-client.ps1`，需要系统 .NET Framework C# 编译器，并通过 `-RclonePath` 提供从官方获取的 x64 `rclone.exe`，通过 `-RcloneLicense` 提供对应 COPYING 文件。脚本输出安装包、便携 ZIP 和校验清单。

WinFsp 不内嵌在分发包中，由用户/IT 从官方安装；因此首次在线安装该组件需要网络。内网无外网访问时，IT 可提前从 <https://winfsp.dev/rel/> 获取并安装官方 MSI。

该客户端接入现有第一版服务器，无需改动服务器数据库。实际盘符挂载需要现场安装 WinFsp 后测试；不能将协议测试等同于已完成系统驱动安装。
