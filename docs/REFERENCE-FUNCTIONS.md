# 参考云盘功能对照

参考范围：用户提供的公司云盘，以及当前登录账号在网页上可见的功能。仅查看界面与对话框，没有创建外链、发布资料库、修改权限或改变参考站文件。此文件不保存参考站账号密码、员工名单或业务资料。

## 已观察的功能

| 模块 | 参考界面可见能力 | 本项目实施范围 |
|---|---|---|
| 资料库 | 我的资料库、新建资料库、加密选项、已删除资料库 | 独立资料库、所有者、软删除恢复、加密库 |
| 共享来源 | 共享给我的、公共资料库、群组共享 | 用户共享、群组共享、公共资料库与权限筛选 |
| 群组 | 群组列表、新建群组、同一资料库出现在多个群组中 | 群组与资料库分离，成员与共享权限管理 |
| 文件 | 上传、新建、文件夹、Markdown、Word、Excel、PPT | 文件上传下载、文档创建、移动复制及批量操作 |
| 视图 | 列表、格点、分栏、属性、标签 | 多种目录视图、文件属性、标签与检索 |
| 内部共享 | 共享给用户、共享给群组、文件夹共享管理 | 资料库及文件夹的用户／群组授权与撤销 |
| 外链 | 共享链接、上传链接、密码保护、自动过期 | 文件／文件夹下载分享、收件上传、密码与有效期 |
| 外链管理 | 访问次数、过期时间、查看与删除、清理无效链接 | 外链清单、访问统计、失效与撤销 |
| 收藏 | 收藏夹、资料库星标 | 资料库与文件收藏 |
| 历史 | 文件活动、资料库历史、回收站 | 活动流、文件版本、快照与恢复、回收站 |
| 发布 | 发布资料库，按 URL 对任何人开放 | 可撤销的资料库公开阅读入口 |
| 设备 | 平台、设备名、IP、最后访问时间 | 设备记录、连接密码与撤销、Windows 助手 |

## 兼容与验证原则

- 原分组和文件保留；旧分组目录升级为默认共享资料库，现有文件 ID、账号和连接密码继续兼容。
- 网页、下载、分享外链及电脑挂载必须使用一致的权限检查；只共享某个文件夹不能访问其余目录。
- 文件写入与恢复保留原子提交、并发冲突检查；加密功能必须实际加密文件内容，不用“仅隐藏界面”的方式代替。
- Office 在线编辑以可自建的文档编辑服务集成实现；功能代码与实际部署、兼容性验证分别记录。
- 未查看到的管理员后台、产品内部实现和当前账号无权访问的功能，不能声称已经逐项复刻。

0.3.0 已接入表中功能，包括加密内容保存、目录和外链授权、快照恢复、公开分享、上传收件以及设备活动。在线 Office 接口依赖管理员部署的 ONLYOFFICE Docs。实测范围见 `VALIDATION.md`。
